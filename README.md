# DNSC-6330-Individual_Homework_05
Adversarial ML audit of COMPAS classifiers for DNSC 6330 Homework 05. Tests logistic regression and gradient-boosted trees under PGD evasion, label-flip poisoning, and membership inference, with focus on AUC, subgroup FPR, AIR, PSI drift, fairness, privacy, and robustness.
